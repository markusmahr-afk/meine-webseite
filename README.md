# Altstadtfleischerei Mahr – Webseite (Entwurf)

Einfache Webseite für die Altstadtfleischerei Mahr in Sonneberg.

- `index.html` – Startseite (Über uns, Angebot, Partyservice, Öffnungszeiten, Kontakt)
- `impressum.html`, `datenschutz.html` – Pflichtseiten (noch zu ergänzen)
- `style.css` – Gestaltung
- `fonts/` – lokal eingebundene Schriften (Kaushan Script, Lora; SIL Open Font License)

Gelb markierte Stellen sind Platzhalter. Vor dem echten Start die Zeile
`<meta name="robots" content="noindex, nofollow">` in allen Seiten entfernen.
